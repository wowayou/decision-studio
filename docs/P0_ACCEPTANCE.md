## 传播、一致性与性能观测

`graph.downstream()` 是局部求值与图连线的共同依赖来源。登录变更实际重算 6 个节点，语言变更只重算语言和发布；候选/报告由求值结果重建，不另存一套 UI 事实。恢复忽略导出文件的派生结果，重放用户操作校验来源再重新计算。

固定输入进行了 500 次局部登录变更：中位 **0.019 ms**、p95 **0.079 ms**（本次单元层观测，见日志）。不包含 React 渲染、存储或导入，不是产品时延承诺；未建立大型项目的性能阈值。

3. 不具备安装型离线缓存。保持本机 HTTP 服务可断外网运行；资源加载后断全部网络也已验证，但不承诺关闭服务后的冷启动/刷新。
4. 本机仅保存一个项目，清浏览器数据会丢失；请导出 JSON。格式只支持首版，版本不匹配拒绝迁移。接近 4 MiB 的长期记录导入性能未做压力测试。
5. 服务价格、许可、套餐、身份与内容权限扩展的真实可用性尚未外部核验，输出只能是条件草案，不能直接据此上线。没有采购或账单承诺。
6. 仅测试 Chromium，未跑 Firefox/Safari；没有人工新手研究、完整屏幕阅读器/键盘遍历审查、线上安全审计或生产可靠性验证。
